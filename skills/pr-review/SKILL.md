# PR Review Skill

## Instructions

When given a PR or code:

1. Summarize changes
2. Identify bugs
3. Check edge cases
4. Suggest improvements
5. Evaluate time complexity, naming conventions, and security implications
6. Give final verdict:
   - APPROVE
   - REQUEST CHANGES
